Privacy Policy

DOT Team App · Zeebas Cluster LLP / DOT Advertising · Last updated 4 November 2026

The DOT Team App is an internal HR tool used by the staff and management of DOT Advertising (Zeebas Cluster LLP). It is not offered to the public.

What we store

  • Staff profile details: name, contact details, role and profile photo.
  • Attendance, leave, tasks, end-of-day reports, payroll and internal chat.

This data is used only to run the company's HR, attendance and payroll. It is not sold or shared with advertisers.

Google Drive backups

The company's administrator can connect a Google account so the app can save backup copies of the HR database to that account's Google Drive.

  • The app asks only for the drive.file permission. With it, the app can see and change only the files it creates itself. It cannot read any other file in that Drive.
  • Google user data is used only to write and manage these backup files. It is not shared with anyone else or used for advertising.
  • The Google access token is stored on the company's server and is used only for backups.
  • Access can be removed at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Security

Data is sent over HTTPS. Access is limited by login and by role.
